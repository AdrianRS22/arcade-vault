# SPEC GJ-nova-gallery-01 — NOVA GALLERY: classic gallery

> **Status:** Draft
> **Depends on:** SPEC 06, SPEC 07, SPEC 08, SPEC 11
> **Date:** 2026-11-19
> **Objective:** Create NOVA GALLERY, a three-lane neon shooting gallery with decoys, a six-shot magazine and a manual `R` reload, as a typed engine played at `/games/nova-gallery/play` with its own leaderboard.

## Why this spec exists

NOVA GALLERY is a new game from the game jam. Its theme comes from the pending entry in `references/game-suggestions-todo.md`: "SHOOTER · magenta — shooting gallery lanes, decoys, reload R". There is no reference code and no asset, so the engine is written from the rules in this spec and every visual is drawn on the canvas.

It is the second SHOOTER in the catalog, after ASTEROIDS, and the first game aimed with a crosshair instead of a moving ship. It is also the first game that reads mouse clicks as an action (Arkanoid only reads mouse movement), so this spec defines how the pointer maps to the logical field and how it coexists with the keyboard and the SPEC 11 touch buttons.

The game is open-ended: stages repeat forever with faster lanes and bigger quotas, and a hit-streak multiplier rewards accuracy, so better players always score more.

The second spec, `02-nova-gallery-night.md`, is a distinct variant (the gallery with the lights off). It is a separate catalog row because scores key only on `game_id`.

Types:

```ts
// lib/games/nova-gallery/types.ts
export type NovaState = "intro" | "playing" | "clear" | "gameover";
export type TargetKind = "drone" | "comet" | "nova" | "decoy";

export type NovaGallerySnapshot = {
  score: number; // 0..9_999_999, clamped
  lives: number; // starts at 3
  stage: number; // starts at 1
  hits: number; // real targets hit this stage attempt, 0..quota
  quota: number; // hits needed to clear the stage
  ammo: number; // rounds in the magazine, 0..6
  reloading: boolean;
  state: NovaState;
};

export type NovaOptions = GameOptions & { mode?: "classic" | "night" }; // "night" is used by 02 only

export type Target = {
  id: number;
  kind: TargetKind;
  lane: 0 | 1 | 2;
  x: number; // px, centre
  y: number; // px, centre (lane y, plus the nova bob)
  vx: number; // px/s, sign = lane direction
  r: number; // px, hit radius
  age: number; // s since spawn (drives the nova bob)
};

export type Burst = { x: number; y: number; color: string; t: number }; // 10 particles, t in s
export type Popup = { x: number; y: number; text: string; t: number }; // "+200 x2", t in s

export function createNovaGalleryGame(
  canvas: HTMLCanvasElement,
  callbacks: GameCallbacks<NovaGallerySnapshot>,
  options: NovaOptions,
): GameEngine;
```

Stage curves (`stages.ts`, `s` = stage number from 1):

```ts
// quotaFor(s)       = 10 + 2 * (s - 1)
// speedFactor(s)    = min(2.2, 1 + 0.08 * (s - 1))            // lane speed multiplier
// spawnInterval(s)  = max(0.6, 1.4 - 0.08 * (s - 1)) ± 0.4 s  // per lane, uniform jitter, never below 0.4
// kindWeights(s)    = { decoy: min(0.30, 0.14 + 0.02 * (s - 1)), nova: 0.04, comet: 0.14, drone: rest }
// clearBonus(s, secondsLeft) = 500 * s + 25 * ceil(secondsLeft)
```

Scoring:

- A hit on a drone, comet or nova star adds `points × multiplierFor(streak)` and then increments `streak` and `hits`. `multiplierFor` uses `STREAK_STEPS`: ×1 for streak 0–4, ×2 for 5–9, ×3 for 10–19, ×4 from 20.
- A shot that hits nothing resets `streak` to 0. It costs no points.
- A decoy hit adds 0 points, resets `streak`, removes one life and flashes the screen magenta for `DECOY_FLASH`.
- Meeting the quota adds `clearBonus(stage, secondsLeft)`.
- The score is clamped to `MAX_SCORE` after every addition.

Game states:

| State      | Field             | Clock   | Shots and reload | Leaves to                                                                     |
| ---------- | ----------------- | ------- | ---------------- | ----------------------------------------------------------------------------- |
| `intro`    | empty, frozen     | stopped | ignored          | `playing` after `STAGE_INTRO`                                                 |
| `playing`  | lanes move, spawn | runs    | allowed          | `clear` (quota met), `intro` (clock 0 with lives left), `gameover` (no lives) |
| `clear`    | frozen, no spawn  | stopped | ignored          | `intro` of stage + 1 after `STAGE_CLEAR`                                      |
| `gameover` | frozen            | stopped | ignored          | `intro` of stage 1 only through `restart()` (PLAY AGAIN)                      |

Stage flow:

- Entering `intro`: remove every target, refill the magazine to `MAG_SIZE`, cancel any reload, set `hits = 0`, set `quota = quotaFor(stage)` and the clock to `STAGE_TIME`.
- Clock reaches 0 in `playing` with `hits < quota`: lose one life. With lives left, replay the same stage through `intro` (the score and streak are kept). With no lives, enter `gameover`.
- Decoy hit that removes the last life: enter `gameover` at once.
- `hits` reaching `quota`: add the clear bonus, enter `clear` and remove the remaining targets after it (no points for them). Then `stage + 1`.

Pointer and controls:

- Crosshair: `←` `→` `↑` `↓` or `A` `D` `W` `S` move it at `CROSSHAIR.speed` (diagonals are normalized). It is confined to `x ∈ [0, W]` and `y ∈ [CROSSHAIR.minY, CROSSHAIR.maxY]`.
- Mouse: `pointermove` on the canvas with `pointerType === "mouse"` sets the crosshair to the pointer, mapped from CSS px with `getBoundingClientRect` on every event and clamped like the keyboard. Keys then move it from there; there is no priority switch.
- Fire: `Space` (one shot per press, `pressed()`) or a left-button `pointerdown` with `pointerType === "mouse"` on the canvas. Touch `pointerdown` events are ignored; touch fires through the FIRE button.
- Reload: `R` (`pressed()`). Ignored with a full magazine, while reloading, or outside `playing`.
- A shot needs `state === "playing"`, `ammo > 0`, `!reloading` and `FIRE_COOLDOWN` elapsed. Firing with `ammo === 0` does nothing (no shot, no streak reset). There is no auto-reload.
- `preventDefault` for the four arrow codes and `Space` only. `P`, `Esc` and `M` are not bound. The engine sets `canvas.style.cursor = "none"` and restores the previous value on `destroy()`.

Conventions:

- Logical field `W = 800`, `H = 600`, origin top-left. It is 4:3, so it fills the `.crt-screen` with no letterbox. Backing store scaled by `devicePixelRatio` (cap 2).
- Speeds in px/s, time in seconds, `dt` capped at `MAX_DT`. `resume()` and `restart()` reset `lastTime`. `pause()` calls `input.reset()` so no key is stuck on resume.
- Each frame in `playing` handles input first (move, reload, shots), then moves targets, then spawns, then runs the clock. A quota-completing shot in the same frame the clock hits 0 therefore clears the stage.
- Hitscan: a shot hits the target whose centre is closest to the crosshair among those with distance ≤ `r`. At most one target per shot.
- A target is removed once its centre passes the far `SPAWN_X` edge. Escapes cost nothing.
- `onChange` fires only when a snapshot field differs from the last emitted one. The last emitted snapshot starts as the registry's `initialSnapshot`. The clock is not in the snapshot, so it never triggers `onChange`.
- `onGameOver(score)` fires once per game over, including through `end()`.
- Canvas draws the backdrop (marquee lights band at `y < 90`, three lane rails, the counter band at `y > 500`), targets, bursts, popups, the crosshair with its streak pips (one pip per multiplier level above ×1), the decoy flash, the "STAGE N" banner during `intro` and the clock bar. It draws no SCORE, LIVES, HITS, AMMO, GAME OVER or restart text.
- Target looks (classic skin): drone a cyan bullseye (`#00f5ff` rings on `#0f2a36`), comet a yellow disc with a short tail (`#f5ff00`), nova a gold four-point star (`#ffcf3a`), decoy a green diamond with a white core (`#00ff88`, `#e6e9ff`). Shapes differ, so the decoy is recognisable without colour.
- Skin (`classic`) mirrors `app/globals.css`: background `#0a0a0f` (`--bg`), rails `rgba(0, 245, 255, 0.18)` (`--line`), marquee bulbs `#ff006e` (`--magenta`) and `#ffcf3a` (`--gold`), crosshair `#e6e9ff` (`--ink`), banner and popups `#ff006e`, clock bar `#00f5ff` turning `#ff006e` at `CLOCK_BAR.warn` seconds, decoy flash `rgba(255, 0, 110, 0.25)`. Glow (`shadowBlur`) only on the crosshair and the nova star, never on bursts or popups.

Edge cases:

- Pausing during a reload freezes the reload; it completes after `RELOAD_TIME` of playing time in total.
- A stage clear or a lost stage during a reload cancels it; the next `intro` refills the magazine anyway.
- Shots, `R` and key presses during `intro`, `clear` and `gameover` are dropped, not queued.
- The mouse leaving the canvas leaves the crosshair where it was.
- `end()` in any state (including `intro`) goes to `gameover` with the current score; a second `end()` does nothing.
- `restart()` from any state starts stage 1 with score 0, 3 lives, streak 0 and a full magazine.
- Two targets within one radius of the crosshair (possible only inside one lane): the closest centre wins; a tie picks the earlier spawn.

## Risks

| Risk                                                        | Mitigation                                                                                                                   |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| StrictMode double mount starts two loops                    | `destroy()` cancels the rAF, detaches input and pointer listeners; `GameCanvas` already guards with `cancelled`.             |
| Input steals keys from the modal                            | Shared input ignores `input`, `textarea` and contenteditable targets; the initials criterion covers `W A S D R` and Space.   |
| Cursor stays hidden after leaving the page                  | `destroy()` restores the saved `canvas.style.cursor`; a criterion checks it.                                                 |
| Mouse mapping off when the CRT is scaled                    | `getBoundingClientRect` on every pointer event; the field is 4:3 with no letterbox.                                          |
| Touch taps fire twice (canvas tap plus FIRE button)         | Canvas pointer listeners act only on `pointerType === "mouse"`; touch fires through the FIRE virtual key.                    |
| Blurry canvas on high-DPI                                   | Backing store scaled by `devicePixelRatio` (cap 2).                                                                          |
| `dt` jump after pause or tab switch                         | `dt` cap of 0.05 s; `resume()` and `restart()` reset `lastTime`.                                                             |
| `shadowBlur` cost with many targets and bursts              | Glow only on the crosshair and nova stars.                                                                                   |
| Difficulty curve too easy or too hard                       | Quota, speeds and decoy share live in `stages.ts` as first values to tune in review.                                         |
| Decoy and drone confused by colour-blind players            | Different shapes (diamond vs bullseye), not only colour.                                                                     |
| Four HUD stats wrap at 375 px                               | Step 8 checks the HUD with `/frontend-design`; AMMO uses short values (`6/6`, `RELOAD`).                                     |
| Seed timestamp or sort order collides with another jam spec | Timestamp and sort order are past every existing and planned value; re-check `supabase/migrations/` before writing the file. |
| Cached game list does not show the new row until rebuild    | Step 1 restarts the dev server; production needs a rebuild or `games` tag invalidation.                                      |
| Scores forgeable                                            | Accepted in SPEC 07; saving requires a signed-in player since SPEC 13.                                                       |

## What is **not** in this spec

- The night variant and its catalog row (`02-nova-gallery-night.md`).
- Sound and the shared audio module.
- The `neon` and `retro` skins (`/skin-designer nova-gallery`).
- Tap-to-shoot on the canvas.
- Weapon upgrades, power-ups, bosses, moving lanes and a reload mini-game.
- Gamepad controls, anti-cheat and server-verified scores.
- Schema changes, a plugin system beyond the registry, and redirects.
- Any change to `references/`.

Each one of those, if it lands, goes in its own spec.
