## Project

Arcade Vault: a platform to play games online and compete for the highest score. The README says the project follows Spec Driven Design (`/spec` and `/spec-impl` skills, installed via `npx skills@latest add Klerith/fernando-skills`). The code is currently the untouched Create Next App scaffold (`app/page.tsx`, `app/layout.tsx` only).

## Commands

- `npm run dev` — dev server (Turbopack)
- `npm run build` / `npm start` — production build / serve
- `npm run lint` — ESLint (flat config, `eslint.config.mjs`)
- No test runner is configured yet.

## Next.js version warning

This is Next.js 16.4.5 with React 19.3 and has breaking changes versus common training data. Before writing Next.js code, read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`; start at `index.md`) and heed deprecation notices. `AGENTS.md` is auto-regenerated by `next dev`; commit it rather than removing it.

## Architecture notes

- App Router only (`app/`). Root layout types its props with the global `LayoutProps<"/">` helper (no import needed), generated by Next typegen.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching` and `experimental.agentFeedback`. Cache Components changes data-fetching and caching semantics, so check the docs before using dynamic APIs or fetching data.
- Tailwind CSS v4, wired through a custom Turbopack rule in `next.config.ts` (`@tailwindcss/turbopack` loader for `*.css`). Theme tokens live in `app/globals.css` (`@theme inline`, with light/dark CSS variables).
- Fonts: Geist and Geist Mono via `next/font/google`, exposed as CSS variables in the root layout.
- TypeScript is `strict`. Path alias `@/*` maps to the repo root (not `src/`).
